# IA Entrenar

Aplicación de entrenamiento personalizado con inteligencia artificial que ayuda a los usuarios a alcanzar sus objetivos fitness de manera eficiente y personalizada.

## Características

- Autenticación de usuarios
- Planes de entrenamiento personalizados
- Seguimiento de progreso
- Calculadora de RM (Repetición Máxima)
- Recetas y planes nutricionales
- Temporizador de entrenamiento
- Dashboard de progreso

## Tecnologías

- Flutter
- Firebase (Autenticación y Firestore)
- Provider para gestión de estado
- Go Router para navegación
